Ejercitación 1 - Responder el siguiente cuestionario
1. Qué es HTML, cuando fue creado, cuáles fueron las distintas versiones y cuál es la última?
2. ¿Cuáles son los principios básicos que el W3C recomienda seguir para la creación de documentos con HTML?
3. En las Especificaciones de HTML, ¿cuándo un elemento o atributo se considera desaprobado? ¿y obsoleto?
4. Qué es el DTD y cuáles son los posibles DTDs contemplados en la especificación de HTML 4.01?
5. Qué son los metadatos y cómo se especifican en HTML?

1) HTML (HyperText Markup Lenguage), creado por Tim Berners-Lee en 1991, es un lenguaje de marcado utilizado para estructurar y organizar el contenido de la página web. Mediante etiquetas, permite definir elementos como títulos, párrafos, imágenes, enlaces, listas, tablas y formularios. Es decir, HTML define la estructura y contenido de una página web, pero no su apariencia ni su comportamiento  
    HTML 1.0 (1991), fue la primera version, permitia estructurar documentos mediante títulos, párrafos, listas y enlaces
    HTML 2.0 (1995), primera versión estandarizada oficialmente. Incorporó los formularios
    HTML 3.2 (1997), incorporó nuevas posibilidades de formato, como tablas, applets y texto alrededor de imágenes. 
    HTML 4.0 (1997), introdujo importantes mejoras relacionadas con las hojas de estilo (CSS), scripts, formularios y accesibilidad
    HTML 4.01 (1999), fue una actualizacion de HTML 4.0 que corrigió errores y realizó algunas mejoras 
    XHTML 1.0 (2000), fue una reformulación de HTML 4.01 siguiendo las reglas de XML, buscando una sintaxis más estricta
    HTML 5 (2014), incorporó elementos semanticos como <header>, <nav>, <section> y <footer>, ademas de soporte nativo para audio, video, gráficos y formularios más avanzados 
    HTML Living Standard (actualidad), desde HTML 5, ya no utiliza versiones numeradas 

2) Los principios básicos que recomienda el W3C para la creación de documentos HTML buscan que las páginas sean correctas, accesibles, interoperables y fáciles de mantener. Los principales son:
- Utilizar HTML para estructurar el contenido, no la apariencia
- Separar contenido y presentación 
- Utilizar elementos semánticos, elegir cada etiqueta según el significado del contenido 
- Crear documentos válidos y bien estructurados, respetar las reglas y sintaxis de HTML para evitar errores y problemas de interpretación 
- Garantizar la accesibilidad, crear documentos que puedan ser utilizados por la mayor cantidad de personas posible, incluyendo aquellas con discapacidades 
- Favorecer la interoperabilidad, utilizar estandares web para que los documentos funcionen correctamente en diferentes navegadores, dispositivos y plataformas 
- Evitar tecnologías o características obsoletas
- Utilizar atributos correctamente, proporcionar información adicional mediante atributos si es necesario 

3) 
Desaprobado (deprecated): un elemento o atributo se considera desaprobado cuando todavía puede utilizarse, pero se recomienda no utilizarlo porque existe una alternativa mejor o porque se planea retirarlo en un futuro

Obsoleto (obsolete): un elemento o atributo se considera obsoleto cuando ya no forma parte del estándar actual y no deberia utilizarse en documentos nuevos. Puede seguir siendo reconocido por algunos navegadores por compatibilidad con páginas antiguas, pero ya no se recomienda su uso

4) DTD (Document Type Definition)  es una definicion de tipo de documento. Es un conjunto de reglas que establece que elementos, atributos y estructura puede tener un documento HTML. 
Se declara al comienzo del documento mediante <!DOCTYPE>. Sirve para indicar que versión y tipo de HTML se está utilizando. 

DTDs de HTML 4.01: 
1. Strict (Estricto): incluye los elementos y atributos considerados estructurales de HTML, pero excluye los elementos y atributos destinados a controlar la presentación
2. Transitonal (Transicional): permite utilizar elementos y atributos de presentación que habían quedado en desuso, facilitando la transición desde versiones anteriores de HTML hacia una separación entre estructura y presentación.
3. Frameset: similar al Transitional, pero permite utilizar frames (marcos) para dividir la ventana del navegador en diferentes documentos.

5) Los metadatos son datos que proporcionan información sobre otros datos. En HTML, permiten describir las características del documento, como su autor, descripción, palabras clave, codificacion de caracteres o instrucciones para los navegadores
Los metadatos se especifican principalmente mediante <meta>, con distintos atributos, que se coloca dentro de la sección <head> del documento HTML
